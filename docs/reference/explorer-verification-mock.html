Scheme: canonical JSON with sorted keys, SHA-256 through the browser's Web Crypto, leaves prefixed 0x00 and interior nodes 0x01 in the style of Certificate Transparency. Private records carry a 32-byte salt.

    
Demonstration salts here are derived deterministically so the batch root is stable between visits. Production salts are random and never leave the owner.
