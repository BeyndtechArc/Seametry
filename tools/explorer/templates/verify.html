What this demonstration is and is not

    
    
      
  • The scheme is real. The bodies are invented, because no mainnet transaction has been made yet.
    • 
      
  • The batch was sealed by the Go engine. This page shares no code with it and reimplements the canonicalization, leaf composition and Merkle path from the specification. CI fails if the two ever disagree by a byte.

  • This root is not written on-chain yet. Once it is, step 4 also checks it against the Solana memo transaction, signed by a published anchor key.
