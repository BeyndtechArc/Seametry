Seametry explains itself here, in one place. Each page answers one question,
and every figure on it carries its source, its age and its evidence state, as
it does in the product.

## Where to start

- [How it works](/docs/how-it-works): the basket as a mechanism, from assembly to the Hall.
- [The Key](/docs/the-key): what the Hall can never do, and what stays with each issuer.
- [The exit](/docs/papers/the-exit): how a holder leaves, stated against the committed evidence.

## How the docs are checked

A page that states a figure from data is generated from that data, so the two
cannot disagree. Search runs on an index built with these pages inside this
site; no query is sent to another service.
