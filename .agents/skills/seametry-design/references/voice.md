# Voice

How Seametry speaks in the interface. Marketing and long-form copy additionally pass through STORM-VOICE-SYSTEM.md.

## Register

Calm authority. The voice of a senior specialist at an auction house: exact, unhurried, never selling. Dread, where it appears, is quiet and factual.

- Lead with the fact or the collision, never with a definition.
- Active voice, sentence case, plain verbs.
- One idea per sentence on product surfaces.
- No exclamation marks, no emoji, no em dashes, no arrows appended to actions.

## Lexicon

| Use | Never |
|---|---|
| issuer, reference observation, executable quote, settled result | true price, fair value, real price |
| verified, unverified, stale, unavailable | safe, risky, trusted, legit |
| the issuer can freeze this | frozen assets are dangerous |
| grade: entitlement, certificate, interest | real stock, fake stock, synthetic |
| you receive no less than | guaranteed, up to |
| no observation | N/A, unknown, error |
| key, strike, melt, hallmark, seal | mint, burn, receipt (in interface copy) |
| provenance, condition | risk score, rating |
| returns separated into price movement, reinvested dividends, opted-in yield | APY, yield (for price movement), gains (blended) |

No sentence recommends direction, size, timing or suitability.

## Formats

**Amounts.** Tabular numerals; thousands separators; unit after the number ("1,000 USDC"); never more decimals than the asset's scale supports. Share quantities show the scale the mint uses.

**Change.** Sign always shown: "+4.21", "−0.18" (true minus sign, U+2212). No colour.

**Ages.** Compact on screen ("2s", "47d"), full in accessible labels ("2 seconds", "47 days"). Age always attached to the value it qualifies.

**Timestamps.** Relative on screen, absolute UTC on focus, labelled by kind: observed, received, effective, settled.

**Serials.** Full, never truncated. Digests may truncate in the middle with the full value available.

## Buttons

Verb plus object, and the name survives the whole flow: "Approve and sign" produces "Signed". "Verify" produces "Verified" or "Does not match". Never "Submit", "Continue", "OK", "Learn more".
